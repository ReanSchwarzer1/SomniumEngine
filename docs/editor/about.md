# About Somnium

Somnium Engine is licensed **MIT OR Apache-2.0**. Pick either.

Editor chrome is **Nocturne Atelier** — cool night panels, a lunar indigo accent used only for focus, selection, active modes and primary actions, and a measured density grammar. Layout slots follow Unreal Editor information architecture (Outliner, Details, Content Drawer) so DCC habits transfer. Paint, icons, widgets and the Eclipse **S** mark are original work on the existing Fyrox-inspired toolkit. No Slate, UMG, Starship or Lumina art is copied.

Type is Inter (Regular, Medium, SemiBold) with JetBrains Mono for numbers, paths and the log — both SIL OFL 1.1. Numeric fields use the monospaced face so a value cannot shift its row while you scrub it. Utility icons are Tabler (MIT); the sixteen engine-specific glyphs and the brand marks are original, drawn on Tabler's 24 × 24 grid so the two sets sit together. Full provenance, versions and modifications are in THIRD_PARTY_NOTICES.md and ATTRIBUTION.md at the repo root.

This Help overlay is curated editor documentation, not a dump of engineering phase plans. Pages are added as the editor grows — Welcome, Viewport, Shortcuts, Content Drawer, About, Outliner, Terrain, Water, and Lighting. The chrome is a living product, not a finished UI pass: parts of it (Content Browser filters and previews, screen-reader support, text shaping for non-Latin scripts) are still being written.
