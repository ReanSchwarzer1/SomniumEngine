# Shortcuts

## General

- **F1** — this Help (Welcome, Viewport, Shortcuts, Content Drawer, About, Outliner, Terrain, Water, Lighting)
- **Esc** — close the top popup, Help, or command palette; exit immersive play
- **Ctrl+P** or **Ctrl+Shift+P** — command palette
- **Ctrl+S** — save scene · **Ctrl+N** — new scene
- **Ctrl+Z / Ctrl+Y** — undo / redo
- **Ctrl+D** — duplicate · **Delete** — delete
- **Ctrl+Space** — show or hide the Content Drawer

## Viewport

- **RMB + WASD/QE** — fly (edit mode) · **Shift** — faster
- **Play** — possess the Outliner Camera · **Stop** — restore the fly-cam
- **RMB + scroll** — camera speed
- **T / R / S** — move / rotate / scale
- **L** — light gizmos
- **F5** — shading mode · **F9 / F10** — GPU draw / GPU frustum A/B (15B). Camera **Frustum Cull** in Details is the CPU early-out (CR-B), independent of F10.

## Terrain and foliage

- **F6** — terrain edit · **1–6** — Raise, Lower, Smooth, Flatten, Noise, Paint
- **[ ]** — brush size · **- =** — strength
- **F8** — foliage tools

## Bottom tray

- **Content Drawer** button — dock or hide the browser
- **Output Log** button — show the log instead of the drawer
