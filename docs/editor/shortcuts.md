# Shortcuts

## General

- **F1** — this Help (Welcome, Viewport, Shortcuts, Content Drawer, About, Outliner, Terrain, Water, Lighting)
- **Esc** — close exactly one layer, in this order: modal → command palette →
  popup → drawer → search filter → selection. Then exit immersive play.
- **Tab / Shift+Tab** — move between shell regions: application bar → mode bar →
  viewport context → tool rail → Outliner → Details → drawer → status. The
  focused region shows a 1 px indigo ring.
- **Ctrl+P** or **Ctrl+Shift+P** — command palette
- **Ctrl+S** — save scene · **Ctrl+N** — new scene
- **Ctrl+Z / Ctrl+Y** — undo / redo
- **Ctrl+D** — duplicate · **Delete** — delete
- **Ctrl+Space** — show or hide the Content Drawer

## Viewport

- **RMB + WASD/QE** — fly (edit mode) · **Shift** — faster
- **Play** — possess the Outliner Camera · **Stop** — restore the fly-cam
- **RMB + scroll** — camera speed
- **T / R / S** — move / rotate / scale
- **L** — light gizmos
- **F5** — shading mode · **F9 / F10** — GPU draw / GPU frustum A/B (15B). Camera **Frustum Cull** in Details is the CPU early-out (CR-B), independent of F10.

## Terrain and foliage

- **F6** — terrain edit · **1–6** — Raise, Lower, Smooth, Flatten, Noise, Paint
- **[ ]** — brush size · **- =** — strength
- **F8** — foliage tools

## Details panel

- Click the **indigo dot** in a row's left gutter to revert that property. It is
  one undo step. The dot appears when a value differs from what it held at the
  last save, scene load, or change of selection.
- **Search** filters sections. **Esc** clears the filter before it closes anything else.

## Workspaces

- **Window menu** — switch between Layout, Terrain, Foliage, Lighting,
  Materials, Debug and Play. Each sets the panel widths and which bottom panel
  is showing.
- **Window → Reset workspace** — return the current workspace to its shipped
  arrangement.
- Splitter positions are remembered per session; the right column keeps its
  width when you move the window to a different monitor.

## Bottom tray

- **Content Drawer** button — dock or hide the browser
- **Output Log** button — show the log instead of the drawer
