# Shortcuts

- **Ctrl+P / Ctrl+Shift+P** — command palette
- **Ctrl+Z / Ctrl+Y** — undo / redo (transform and lights)
- **Ctrl+S / Ctrl+N** — save / new scene
- **Ctrl+D** — duplicate · **Delete** — delete
- **Ctrl+Space** — Content Drawer (toggle, including close)
- **F1** — this Help · **Esc** — close popup / Help / Drawer
- **F5** — shading mode · **F6** — terrain edit · **F8** — foliage
- **F9 / F10** — GPU draw / frustum A/B
- Terrain edit: **1–6** brushes, **[ ]** size, **- =** strength
