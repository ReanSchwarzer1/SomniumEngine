# Viewport & camera

- **Right mouse + WASD/QE** — fly (Shift = faster)
- **RMB + scroll** — camera speed, also the slider on the viewport toolbar
- **LMB** — pick an entity
- **T / R / S** (W/E/R when not flying) — translate / rotate / scale gizmos
- **L** — light gizmos
- The centre region is the 3D viewport. UI chrome around it does not steal fly-cam input.
