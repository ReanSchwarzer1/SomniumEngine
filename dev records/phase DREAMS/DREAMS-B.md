# DREAMS-B · GRAIN — one sampler under the frame

> The useful result is not a prettier noise function. It is one owned sampling
> resource, one repeatable fixture, and switches that remain measurable in both directions.

**Status:** complete, amended 2026-09-01, against f13bbaa on dev.

## Decision

DREAMS-B lands two independent features, on by default after the product
decision on 2026-09-01:

- Shared Grain replaces the private sampling sequences in GTAO,
  volumetrics, ReSTIR DI/GI and TAA with one 64×64×64 RGBA rank atlas.
- Terrain STF replaces the strongest-four terrain layer's trilinear
  mip choice with one stochastic mip choice per lookup. Its mask slice advances
  once per frame and TAA integrates the result.

Both are authored live in **Details > DREAMS Sampling**. The environment rails
remain for reproducible runs: SOMNIUM_DREAMS_GRAIN=0 and SOMNIUM_DREAMS_STF=0
force a feature off; explicit 1 forces it on and owns the corresponding editor
control for that process.

The atlas is generated by the first in-engine Slang shader. Existing WGSL
passes only receive narrow adapters; DREAMS did not fork the renderer or grow
a second shader registry.

Collaborative filtering does **not** land. Once STF's slice advanced with the
frame, the frame-240 captures showed no persistent magnification noise that
justified another pass. Somnium's subgroup support also remains an optional
device feature. Adding a subgroup filter here would have answered no measured
problem and weakened DREAMS' no-new-requirement rule.

## Fixture first

tools/ghostfence/thermometer.py owns the controls:

| Control | Value |
|---|---|
| Seed | 0x5eed_b10e |
| Camera | named coastal-ground / island-ground rail |
| Rail movement | first 120 frames, then held |
| Picture | frame 240 |
| Timing | 180 warm-up + 300 measured frames |
| Render size | 1920×1032 in these runs |
| Sun | elevation 45°, azimuth 120° |

When one B switch is measured, the fixture pins the companion B switch to 0;
ambient SOMNIUM_DREAMS_* variables are cleared first. Default therefore proves
the selected feature's authored default without confounding the other feature.

examples/hello_engine/src/dreams_fixture.rs refuses unknown rail names. The
camera is frame-indexed rather than delta-time-integrated, so machine speed
cannot change where the capture lands. --state can rerun one failed member
without silently replacing the other half of an A/B.

## The resource

GrainMasks owns:

- a 64×64 progressive farthest-point rank tile;
- 64 toroidally shifted and Cranley-Patterson-rotated temporal slices;
- four decorrelated channels;
- a 1 MiB Rgba8Unorm texture array for compute passes;
- a 16 KiB uniform mirror for terrain shading, because that stage was already
  at both the portable sampled-texture and storage-buffer limits;
- the retained 1 MiB CPU cook used to advance that uniform mirror.

The mask build is one startup dispatch. Vulkan adapters with
PASSTHROUGH_SHADERS execute the checked-in Slang SPIR-V; other adapters upload
the same logical atlas from the deterministic CPU cook. No feature became
required.

.somtime now writes dreams_grain_consumers. It reported 0 off, 4 for the Grain
fixture (GTAO, volumetrics, TAA and ReSTIR GI on this configuration), and 1 for
the STF-only fixture.

## Slang became a real path

The A2 open questions now have concrete answers:

| Question | B answer |
|---|---|
| Compiler supply | No vendored binary and no networked build script. tools/slangcook pins Slang 2026.16.1 and its archive SHA-256, discovers SOMNIUM_SLANGC, PATH, or the ignored target/slang-2026.16.1 toolchain, and refuses a version mismatch. |
| One registry | ShaderSystem registers both WGSL source modules and validated SPIR-V artifacts. registered_names() has one answer. |
| Artifact trust | SPIR-V magic, word alignment and named entry points are checked before an explicitly unsafe trusted-artifact registration. The public safe API cannot admit arbitrary passthrough bytes. Checked-in artifacts reproduce with python tools/slangcook/run.py --check. |
| Hot reload | WGSL keeps its live reload, including the DREAMS_STF composition define. Slang has deterministic recook and diagnostics, but pipeline-preserving live replacement is still open; a changed .slang file must be cooked and the Rust embed rebuilt. This is not presented as solved. |
| First shader | dreams_grain.slang is small but real: the engine created its pipeline and executed it on the Vulkan adapter. The runtime entry is main; the source entry is build_masks. |

The checked-in dreams_grain.spv is 6,828 bytes, SHA-256
f708671ffe51f4bc2a90186b9c7210cb43efe682fe88796e4864ec8a9c15ed52.

Policy from this phase onward: new DREAMS shader modules are authored in Slang.
Edits inside an existing WGSL module remain WGSL adapters; a policy that forced
a rewrite of the 55-module bindless floor would be theatre, not adoption.

## THERMOMETER

All values below are means from 224 collected profiler samples within the
300-frame measurement window. Runs are sequential, so sub-millisecond
differences are reported, not promoted to causal claims.

### Shared Grain switch

| Map | State | Frame ms | GTAO ms | ReSTIR GI ms | consumers |
|---|---:|---:|---:|---:|---:|
| Coastal ground | off | 24.7035 | 1.1489 | 3.9302 | 0 |
| Coastal ground | on | 22.8866 | 0.6797 | 3.1571 | 4 |
| Island ground | off | 17.8115 | 0.7033 | 2.2272 | 0 |
| Island ground | on | 17.8774 | 0.5365 | 2.2845 | 4 |

The sign is not consistent across maps, so the honest cost statement is
**inside between-session variation at this fixture**. The atlas itself has no
per-frame build cost.

### Terrain STF switch

| Map | State | Frame ms | Shading ms | consumers |
|---|---:|---:|---:|---:|
| Coastal ground | off | 24.5987 | 13.7974 | 0 |
| Coastal ground | on | 22.6135 | 12.8538 | 1 |
| Island ground | off | 19.0511 | 8.9025 | 0 |
| Island ground | on | 18.4094 | 8.4824 | 1 |

Those pairs favour STF, but the earlier static-slice run moved in the opposite
direction (+0.4214 ms Coastal Shading, +0.1456 ms Island). The sessions do not
support a performance claim. STF is default-on by product decision, not by a
performance claim; its Details toggle and explicit =0 rail preserve the control.
